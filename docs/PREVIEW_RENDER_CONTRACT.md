# Preview Render Contract

The render contract binds task ID, AOI, target CRS, dimensions, selected primary imagery, source IDs, adapter IDs, themes, roles, z-order, opacity, blend mode, resampling, color profile, band mapping, byte caps, network policy, adapter capability hashes, source allowlist hash, theme registry hash, and renderer implementation version. Volatile timestamps and machine-local paths are excluded from the contract hash.
