# FasterRaster

FasterRaster turns explicit raster study contracts into bounded acquisitions, harmonized analyses, reproducible evidence, and publication-ready outputs.

The `v1.0.0-beta.1` public beta is designed for technical evaluation. It provides deterministic templates and plans, exact-year source validation, bounded local execution, transactional handoffs, checksums, provenance, strict reuse, and implemented CDL/NAIP-backed workflows.

Start with [Installation](installation.md), then complete the [five-minute quickstart](quickstart.md). The quickstart is offline and does not require an existing cache.

## Why use it?

A raster result is more useful when the source, year, extent, grid, resampling policy, network transfer, and derivation are explicit. FasterRaster records those decisions and fails closed when a required contract cannot be satisfied.

## Beta interpretation boundary

The human-development workflow uses USDA Cropland Data Layer non-agricultural classes as a crop-focused mapped-development proxy. It is not authoritative evidence of urbanization, population or economic growth, construction dates, occupancy, cadastral approval, or causality.

See [Known limitations](limitations.md) before interpreting any output.
