# Release notes

The current published public release is `v1.0.0-beta.5`, mapped to Python package
version `1.0.0b5`.

Canonical registry label: `1.0.0b5 (published beta)`.

This beta publishes the post-beta.4 public development tranche, including:

- truthful release and capability-registry v2 metadata;
- executable documentation and generated-surface drift gates;
- `fr update status`;
- explicitly authorized, bounded `fr update check`;
- release-manifest and deterministic update-receipt contracts;
- honest aggregate adoption-metric foundations;
- public pseudonymous Handle Registry schemas, validation, governance, and
  deterministic empty registry surfaces;
- the existing Source Pack, STAC v2, PRISM, preview-template, classification,
  and planning work present in the tagged public source tree.

Capability release state, evidence tier, and execution boundary remain
independent claims. A public contract does not imply that every provider,
product, geography, date, credential mode, or output is executable.

This beta does not include automatic update application, anonymous Handle
Registry intake, signing-key generation, telemetry, PyPI publication, or
private authenticated execution.
