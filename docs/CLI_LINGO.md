# FasterRaster Kitchen Mode Lingo

Kitchen Mode is a display overlay for the CLI. It makes exploratory commands easier to scan while keeping JSON keys, schemas, manifests, and automation contracts canonical.

Core terms:

- pantry = source atlas
- sauce = source / dataset
- reign = source family or domain
- bucket = readiness/status group
- flavor = variable, layer, or measurement
- crop-cookie = AOI bounds or bbox
- dip = bounded metadata probe
- recipe = stack plan or acquisition plan
- batcher = unlock and stack planner
- goods = verified usable sources
- bads = blocked, gated, or failing sources
- locks = credential gates
- flips = harmonization transforms
- crumbs = metadata, provenance, checksums

Use `--lingo kitchen` for kitchen-first labels, `--lingo standard` for professional labels, and JSON for canonical machine-readable output.
