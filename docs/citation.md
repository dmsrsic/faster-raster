# Citation

Use the repository's [CITATION.cff](https://github.com/dmsrsic/faster-raster/blob/main/CITATION.cff) metadata when citing FasterRaster. Cite the exact release label and retain the study's manifests, receipts, checksums, source years, and methodology alongside the software citation.

For `v1.0.0-beta.1`, the Python package version is `1.0.0b1`. A persistent archive identifier can be added to the citation metadata after one exists; none is invented for this local candidate.
