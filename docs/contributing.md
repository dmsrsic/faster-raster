# Contributing

Create a Python 3.12 virtual environment, install `.[dev,docs]`, and run the offline test suite, quick smoke, beta check, and strict documentation build before proposing a change.

Keep changes focused. Source contracts, scientific interpretation, network policy, output schemas, and public CLI behavior need tests and explicit documentation. Do not commit raster downloads, caches, credentials, or machine-specific paths.

The repository-level [contribution guide](https://github.com/dmsrsic/faster-raster/blob/main/CONTRIBUTING.md) contains the complete checklist. Use the [issue tracker](https://github.com/dmsrsic/faster-raster/issues) for reproducible proposals after the repository becomes public.
