# Hybrid publication

The human-development publisher consumes a finalized, checksum-valid handoff. It can create a regional change hybrid, developed-state view, deterministic hotspot, or combined publication.

Classification controls where imagery is revealed; imagery does not rewrite the analytical raster or its statistics. The publisher records the source handoff checksum, mapping contract hash, imagery year and records, grid, byte counts, and output checksums.

## Buckeye temporal distinction

The Buckeye–Verrado analysis uses CDL years 2008, 2016, and 2021. No intersecting 2021 NAIP catalog records were available for the requested area. The published work therefore uses explicitly selected **2023 NAIP as later visual context**. It must not be described as evidence of conditions in 2021.

This is normal exact-year recovery:

1. the 2021 imagery request fails coverage validation;
2. the error reports available intersecting years;
3. the user explicitly selects 2023;
4. the publication records the analytical years and context year separately.
