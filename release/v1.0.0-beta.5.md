# FasterRaster v1.0.0-beta.5

FasterRaster `1.0.0b5` publishes the validated public development tranche
following beta.4.

## User-visible additions

- Inspect the active installation with `fr update status`.
- Explicitly check the bounded beta or stable release channel with
  `fr update check --allow-network`.
- Distinguish published, unreleased-public, private, planned, and unsupported
  capabilities independently from evidence level and execution boundary.
- Use the public Handle Registry contract and privacy/governance model as the
  foundation for future pseudonymous registration.
- Use deterministic documentation commands and generated release surfaces.

## Safety boundary

This prerelease does not automatically install updates, execute downloaded
code, modify Git, collect usage telemetry, create signing keys, accept registry
submissions, or expose private execution.
