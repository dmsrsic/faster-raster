# FasterRaster v1.0.0-beta.1

`v1.0.0-beta.1` is the first public evaluation release of FasterRaster. The Python package version is `1.0.0b1`.

FasterRaster is a source-aware raster orchestration compiler: an explicit study workfile becomes a deterministic source plan, bounded acquisition, harmonized analysis, finalized evidence handoff, and—where implemented—a publication-ready visual.

## Highlights

- Installed `fr` CLI with deterministic templates and offline validation.
- Exact-year CDL and NAIP coverage behavior with no silent substitution.
- Live USDA CDL multi-epoch mapped-development proxy workflow.
- Common-footprint trend reconciliation and explicit interval evidence.
- Regional and deterministic 1 m hotspot NAIP hybrid publication.
- Transactional handoffs, checksums, provenance, bounded workers, byte ceilings, and strict zero-network reuse.
- Reproducible offline CI, clean wheel installation checks, and a static documentation site.

## Scientific interpretation

The human-development workflow maps USDA CDL non-agricultural classes as a crop-focused mapped-development proxy. It does not establish authoritative urbanization, population growth, economic growth, construction dates, occupancy, cadastral status, or causality. Apparent changes can include classification or source-production differences.

The Buckeye example analyzes CDL years 2008, 2016, and 2021. Its 2023 NAIP layer is later visual context selected explicitly after the source catalog reported no intersecting 2021 record; it is not evidence of 2021 conditions.

## Boundaries

PRISM static ZIP evidence remains fixture-only. Additional adapters, provider-neutral credential references, paid or restricted sources, richer classifiers, scheduler-neutral packages, and cluster execution are roadmap directions rather than implemented beta capabilities.
